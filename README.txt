NOVARA - installable web app (PWA)
1) Upload this whole folder to any free HTTPS host (Netlify Drop, GitHub Pages, Cloudflare Pages).
2) Open the link in Chrome on Android -> menu -> "Install app" / "Add to Home screen".
3) For an APK / Google Play: paste the link into pwabuilder.com and download the Android package.
Note: accounts, chat and follows are stored on the device only. Real multi-user needs a backend.
